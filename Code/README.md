# Reproducing the numerical results

Extract the reproducibility archive and use Python 3.12. Save the
public Tecator text file from StatLib in `Code/data/tecator.txt`
before running the spectroscopy analysis and checks. The dataset
and split are described in `Code/data/README.md`.

Run the following commands from the directory containing `Code/`.

```sh
python -m pip install -r Code/requirements.txt
python Code/reproduce.py
python Code/interpolation_peak.py
python Code/nested_risk.py
python Code/dimension_selection.py
python Code/tecator.py
python Code/check_results.py
```

Figures 1 and 2 (method comparison and component selection) are
generated by `reproduce.py` using seed 20261119. Figure 3 (risk peak)
is generated by `interpolation_peak.py`. The two signal directions
in Table 1 are evaluated by `check_results.py`. The figures go in
`Figures/` and the numerical summaries
in `Code/results/`. `reproduce.py --quick` writes smoke-test outputs
under `Code/quick-results/`.

- `benchmark.csv` contains the Marchenko–Pastur limits, prescribed PLS
  counts, method-specific risks and paired PLS-minus-ridge and
  PLS-minus-least-squares mean differences. Standard errors for
  the differences use the within-replication pairing. Least-squares
  summaries are included away from unit aspect ratio.
- `validation.csv` contains paired differences between two- and
  one-component fits, Monte Carlo standard errors and the fraction of
  replications favouring two components.
- `five-fold-limits.csv` gives the two limiting risks at each aspect ratio
  for the five-fold counterexample.
- `dimension-selection.csv` reports how often the estimated risk selects
  the better of two nested dimensions in 200 Gaussian samples at each
  sample size. `dimension_selection.py` uses seed 704. It estimates
  explained variance by off-diagonal products and certifies the reference
  dimension using a feasible partial least squares score and a ridge lower bound.
- `interpolation-peak.csv` contains the fixed-count and rescaled risk
  curves, the limiting peak profile and finite-sample means and Monte
  Carlo standard errors. Each simulation uses 80 Gaussian samples of size
  600 and unit noise variance. Panel A uses the fully observed one-component
  fits at total signal-to-noise ratio (SNR) 0.1 from the nested experiment
  below, with additional fully observed fits from seed 705. Panel B uses SNR 1.5 and seed 701, with each sample reused
  across component counts. Panel C plots the rescaled risk for eight
  and 32 components. It uses the same central fits as panel B and seed
  703 at the other points. The target local coordinates are ±0.5, ±1, ±1.5 and ±2,
  with dimensions rounded to the nearest integer. The CSV records the
  actual coordinates. Its finite-sample means and standard errors are
  always in units of noise variance, before division by the count plus one.
- `nested-peak.csv` compares four nested dimensions (30, 60, 600 and
  2400) at a common sample size of 600. Only the 31st predictor has a
  nonzero coefficient. Its squared coefficient is 0.1 or 1.5, and the
  noise variance is one. All fits within a replication share the Gaussian
  predictors and noise (80 replications, seed 702). The target is the
  full conditional mean even at the smallest dimension, where the signal
  is omitted. The file reports analytical limits, finite-sample means,
  Monte Carlo standard errors and successive paired mean changes with
  their standard errors for one and 16 PLS components.
- `nested_risk.py` computes `nested-risk.csv` and draws Supplementary
  Figure C.1. Total signal variance is 5, noise variance is 1 and the
  omitted fraction is (1 + gamma) to the power -3 or -5. PLS uses 1, 2,
  5, 10 and 20 components. The other curves are minimum-norm least
  squares, optimally tuned ridge and the zero predictor. At gamma = 1 the
  least-squares limit is infinite. The points use the Monte Carlo means
  in `nested-risk-simulation.csv`. The commands below regenerate this file.

The main-text simulations use conjugate gradients on the normal equations
to fit ordinary PLS. Exact leave-one-out predictions for one and two
components use rank-one deletion formulas. Simulated out-of-sample
conditional-mean risk is squared coefficient error under isotropy.

To compile the article, extract the separate manuscript source archive.
It contains the main and supplementary figure PDFs and the OUP class.
From the extracted directory, compile either document independently with
`latexmk -xelatex main.tex` or `latexmk -xelatex supplement.tex`.

`check_results.py` verifies the fixed-fold counterexamples with rational
arithmetic, the PLS iterates against direct least squares on an
orthogonal Krylov basis, exact leave-one-out predictions against
explicit refits, the benchmark limits against finer quadrature and
the closed-form isotropic ridge risk. It also recomputes the
high-signal PLS-to-ridge ratio from the limiting energy integral,
the local peak profile by quadrature and the numerical dimension
comparisons. For the two signal directions in the correlated-design table,
it computes the two-component PLS risks from exact moments and minimises
ridge risk over the positive stationary points and both endpoints.
An exact rational-moment calculation verifies every nested
risk limit and the signs of the paired simulated risk changes are checked
against those limits. A second PLS implementation checks the selected Tecator
fits by successively deflating the spectra and response. The peak
program checks its finite-count risk formula against independent
Marchenko–Pastur quadrature.

## Regenerating the simulation points in Supplementary Figure C.1

The archive includes the original simulation driver
(`Code/nested_risk_source/run_main_figures_n2000.py`), its local imports
and an entry point that selects the two designs plotted in Figure C.1.
To regenerate the points, activate a separate Python 3.11 environment and
run these commands from the directory containing `Code/`.

```sh
python -m pip install -r Code/nested_risk_source/requirements.txt
python Code/nested_risk_source/reproduce_points.py --workers 3
```

For each of 36 predictor counts, the driver draws 200 independent Gaussian
design matrices with 2000 observations. It uses NumPy's
`SeedSequence([2026093001, n, p, rep])` for repetitions 0 to 199. Each draw
is shared by both omitted-signal exponents and all six fits. The output
`Code/results/nested-risk-simulation.csv` contains 432 rows. Each row
reports the mean prediction risk, its sample standard deviation over
replications and the replication count.

The full run uses 7200 design matrices. Completed batches of ten draws
are saved under `Code/nested-risk-work/checkpoints/`. Rerunning the same
command resumes from these batches. Use `--workers 1` to reduce memory
use. To compare a fresh run with the supplied CSV, choose an empty
`--work-dir` and a different `--output` path. To redraw the figure from
the default output, return to the Python 3.12 environment above and run
`python Code/nested_risk.py`.

## Tecator application

Download the plain-text dataset from StatLib at
<https://lib.stat.cmu.edu/datasets/tecator> and save it as
`Code/data/tecator.txt` before running the last two commands.
The workspace copy can also be used. `Code/data/README.md` records
the data provenance and permission notice.

The primary analysis retains the first occurrence of each distinct
100-channel spectrum in StatLib file order. This yields 158 development
and 35 test spectra, with no spectrum shared across the split. The
four methods tune on the development data and are refitted
before test scoring. The tecator-unique files report this analysis.
The other Tecator files reproduce the original 172/43 split, which
includes exact duplicates. Both analyses produce test scores, candidate
scores and paired test-case bootstrap comparisons. The bootstrap holds
the fits fixed. Running `tecator.py` also writes the case-level
predictions and observed fat percentages used by `check_results.py`.
